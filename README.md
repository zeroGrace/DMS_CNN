# Decomposition Based Multi-Sight CNN: A Global Forecasting Method for Multi-Consumer Electricity Demand from Perspective of Electricity Retailers

Siyue Yang, Qi Sima, Liang Shen, Yukun Bao*

*Center for Modern Information Management, School of Management, Huazhong University of Science and Technology, Wuhan, 430074 CN

This is the PyTorch implementation of the paper "Decomposition Based Multi-Sight CNN: A Global Forecasting Method for Multi-Consumer Electricity Demand from Perspective of Electricity Retailers". The full open-source code will be made available upon publication of this paper.

## Requirements
- Python 3.8
- matplotlib == 3.9.2
- numpy == 1.26.4
- pandas == 2.2.2
- torch == 2.6.0

## Project
- **Core Model Files**  
  - `models/models_dl/dmsCNN.py` - Model architecture of the proposed DMS-CNN. 
  - `models/model_args.py` - Key hyperparameters of DMS-CNN. 
- **Program Entry File** 
  - `run_exp/run_exp_dmsCNN.py` - Launches the experiment and generates the results.
